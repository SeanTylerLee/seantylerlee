Support

STL Apps for Mac · STL Apps LLC

This page is support for the STL Apps Mac app — the studio operations program for projects, billing, books, renewals, and related work on your Mac.

How to reach us

Email seantylerlee@icloud.com.

In the message, include:

  • What you were doing
  • What went wrong
  • Mac model and macOS version (Apple menu → About This Mac)
  • App version (STL Apps → Settings, or About)

Do not email passwords, bank account numbers, API tokens, or a full backup file unless we ask and you have a reason to send them. If a screenshot helps, hide secrets first.

Backups

File → Save Backup… (Command-Shift-B) writes a .stlappsbackup file to a folder you pick. Keep a copy off this Mac. To restore: File → Restore Backup… Restore replaces what is on this Mac with that backup.

What this app is

STL Apps is a personal tool from STL Apps LLC. It is not a hosted service. Your data stays on your Mac unless you export it or email it.

Other products

This page is not support for Permit Path, HaulPath, or Pilot Car 4 Hire. Use those products’ own support channels.
